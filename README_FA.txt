ELINA — بسته وب‌اپلیکیشن برای آیفون
====================================

این بسته یک وب‌اپلیکیشن مستقل (PWA) است. برای نصب آن روی آیفون باید پوشه حاوی فایل‌ها روی یک میزبان HTTPS منتشر شود. سپس با Safari به نشانی منتشرشده بروید و آن را به صفحه اصلی اضافه کنید.

محتویات بسته:
- index.html: رابط کاربری ماشین‌حساب
- math-engine.js: موتور محاسباتی بدون eval
- manifest.webmanifest: مشخصات وب‌اپلیکیشن
- sw.js: نگهداری فایل‌های اصلی برای استفاده آفلاین پس از بارگذاری اول
- icons/: آیکون‌های ELINA

انتشار رایگان با GitHub Pages:
1) در GitHub یک مخزن جدید بسازید. برای مثال نام آن را elina-calculator بگذارید.
2) فایل ZIP را روی رایانه باز کنید (Extract). وارد پوشه ELINA_iPhone_PWA شوید.
3) همه فایل‌ها و پوشه‌های داخل آن را در ریشه مخزن GitHub بارگذاری کنید؛ خود فایل ZIP را به‌تنهایی بارگذاری نکنید.
4) در مخزن به Settings > Pages بروید.
5) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
6) Branch را روی main و پوشه را روی /(root) تنظیم و Save کنید.
7) پس از انتشار، نشانی نمایش‌داده‌شده در بخش Pages را باز کنید. نشانی معمولاً شبیه این است:
   https://USERNAME.github.io/elina-calculator/
   به جای USERNAME نام کاربری GitHub خودتان قرار می‌گیرد.

نصب روی iPhone:
1) نشانی منتشرشده را با Safari باز کنید (نه مرورگر داخل پیام‌رسان‌ها).
2) دکمه Share را بزنید.
3) Add to Home Screen را انتخاب کنید.
4) گزینه Open as Web App را روشن بگذارید.
5) نام ELINA را تأیید و Add را انتخاب کنید.

نکته‌ها:
- انتشار در GitHub Pages عمومی است؛ اطلاعات شخصی یا داده حساس داخل این سایت قرار ندهید.
- برای بارگذاری اولیه به اینترنت نیاز است. بعد از آن فایل‌های اصلی توسط Service Worker ذخیره می‌شوند و اپ برای محاسبات محلی می‌تواند آفلاین باز شود.
- تاریخچه، حافظه و حالت DEG/RAD در حافظه محلی همان مرورگر/وب‌اپ ذخیره می‌شوند. پاک‌کردن داده‌های Safari یا حذف وب‌اپ ممکن است این اطلاعات را حذف کند.
- عملیات گویا/صحیح در موتور با BigInt انجام می‌شوند؛ توابع علمی از اعداد شناور JavaScript استفاده می‌کنند و حدود ۱۵ رقم معنادار نمایش می‌دهند. برای کارهای حساس، نتیجه را با مرجع مستقل بررسی کنید.
- موتور فعلی اعداد مختلط، حل معادلات نمادین، مشتق/انتگرال نمادین و عملیات ماتریسی را ارائه نمی‌کند.
